# 技術報告書の参考文献を Zotero に登録する

## このフォルダのファイル

| ファイル | 役割 |
|---|---|
| `build_zotero_manifest.py` | `../references.json`（参考文献の正本）から `manifest.json` を作る |
| `manifest.json` | 登録する文献の一覧（新規23件、登録済みで案件に含める15件） |
| `zotero_import_constrained_sampling.js` | Zotero に貼り付けて実行するスクリプト |
| `result.json` | 実行すると作られる結果（実行前はない） |

## スクリプトがすること

- まだ Zotero に無い文献23件を登録する
  - 本文を取得できた8件（特許5件・キヤノンのWebページ・Bridson 2007・Wyant & Creath 1992）は、`../sources/` の PDF・HTML をコピーせずリンクで添付する
  - 本文を取得できなかった15件（SPIEの有料論文・Technometrics 等の有料論文・書籍）は書誌だけを登録し、「その他」欄に「本文未取得: 理由」を書く
  - すべてに「未読」タグを付け、テーマのコレクション（`01_半導体プロセス`・`02_フォトニクス・光学シミュレーション`・`04_統計`・`05_資料`）に入れる
- 案件のコレクション `2026-10-04_制約付き最適サンプリング評価` を作り（1階層）、新規の23件と、登録済みの15件を入れる
  - 登録済み15件：Slonaker 1988・US5493402・Adel 2007・Chiu 2012 と、2026-10-03 のアライメント OVL サンプリング最適化調査で登録した11件（WO2020234028A1・Chue 2009・Nikon Litho Booster・US20160334717A1・US20160299438A1・US10692227B2・US4918320A・US12025924B2・JPH1019512A・Felix 2011・Lee 2016）
  - 登録済みの文献には「未読」タグを付けない
- 既存の項目の中身・タグ・コレクションは消さない、書き換えない。何度実行しても二重に登録しない

## 実行手順

1. Zotero を起動する（起動済みならそのまま）
2. スクリプトをテキストエディタで開き、全選択してコピーする
3. Zotero のメニューで［ツール］→［開発］（表示によっては［開発者］）→［JavaScriptを実行］を開く
4. 開いた画面の「Run as async」にチェックを入れる（必須）
5. 左のコード欄に貼り付け（⌘V）、「Run」を押す
6. 右の結果欄の `summary` が次のようになれば完了。同じ内容が `result.json` にも保存される
   - 1回目：新規登録 23 件（うち「未読」タグ 23 件）、登録済みの参考文献を案件コレクションへ 15 件、ファイルのリンク添付 8 件、失敗 0 件
   - 2回目以降：新規登録 0 件、登録済みの再利用 23 件、添付済み 8 件（重複は作られない）
7. 左のコレクション一覧に `2026-10-04_制約付き最適サンプリング評価` ができ、38件が入っていることを確かめる

## 注意

- テーマのコレクションが見つからないときは何も登録せずに止まる（`result.json` の `failures` に名前が出る）
- `field_warnings` は、項目の種類に無い欄を飛ばした記録。登録そのものは成功している
- 文献を追加・修正するときは `../references.json` を直し、`python3 build_zotero_manifest.py` で `manifest.json` を作り直してから実行する
- スクリプトは前回の案件（`技術解説資料/04_露光・Overlay/重ね合わせ制御の進化と展望_ロードマップ_src/zotero/`）で実行済みのものと同じ処理で、パスと案件名だけを変えている
